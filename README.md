## 🚀 Sobre o Projeto

O **Cronômetro Digital** é uma ferramenta interativa desenvolvida com o objetivo de praticar a manipulação de intervalos de tempo em **JavaScript**, utilizando funções assíncronas nativas como `setInterval` e `clearInterval`, além de reforçar o controle do estado da interface durante a execução.

---

## ✨ Funcionalidades

- **Start (Iniciar):** Dispara a contagem regressiva/progressiva do tempo de forma precisa.
- **Stop (Pausar):** Interrompe a contagem no segundo exato do clique sem perder o progresso.
- **Reset (Zerar):** Reinicia a contagem dos contadores e limpa o estado do timer.
- **Interface Intuitiva:** Layout simples, direto e com boa legibilidade em qualquer dispositivo.
